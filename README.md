DSA TASK 3

Description

This repository contains practical implementations of Data Structures and Algorithms (DSA) using C and C++. It demonstrates different data structures, their operations and the use of recursion.

Programs Included

1. Circular Queue – Implements insertion, deletion and display operations using a circular queue.
2. Recursive Programs – Demonstrates recursion through calculating the sum of natural numbers, factorials and Fibonacci sequences.
3. Queue Operations – Implements a linear queue with enqueue, dequeue, overflow, underflow and display operations.
4. Sparse Matrix – Converts a two-dimensional matrix into a sparse representation using arrays and reconstructs the original matrix.
5. Double-Ended Queue (Deque) – Implements insertion and deletion at both the front and rear.

Technologies Used

- C
- C++
- Visual Studio Code

How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Compile the program you want to run using a C or C++ compiler.
4. Execute the generated program.
